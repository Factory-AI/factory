Factory組織には、**User**、**Manager**、**Owner** の3つのメンバーシップロールがあります。各ロールには、その下位ロールの権限が含まれます。

## 概要

| ロール  | 適した対象                                           | アクセスレベル         |
| ------- | ---------------------------------------------------- | ---------------------- |
| User    | 日常的にFactoryを使う個人のコントリビューター       | 標準的な製品アクセス   |
| Manager | メンバー、連携、利用状況を管理するチーム管理者      | 管理者アクセス         |
| Owner   | 請求とアイデンティティ管理を担うビジネスまたはIT責任者 | 組織へのフルアクセス |

## User

User は Factory にアクセスし、中核となる製品体験を利用できます。このロールは、Droid セッションを作成して作業し、個人ワークスペースを使い、自分のアクティビティに関連する情報を確認する必要があるメンバー向けです。

User にできること:

- Factory と Droid を利用する。
- 自分自身の分析データとアクティビティを確認する。
- 自分の個人設定と接続を管理する。
- 組織でメンバーの可視性が許可されている場合、他のメンバーを表示する。

User は、組織全体の設定、請求、メンバー、共有の管理コントロールを管理できません。

## Manager

Manager は User にできることをすべて行えるうえで、日常的な組織運営の大部分も管理できます。このロールは、組織を円滑に運営する必要があるチームリード、ワークスペース管理者、オペレーション担当者向けです。

Manager にできること:

- メンバーを招待する。
- 許可された範囲でメンバーロールを更新する。
- メンバーを削除する。
- 組織のインテグレーションとリポジトリを管理する。
- 組織レベルの分析データと利用状況を確認する。
- 利用上限と利用状況に関するコントロールを管理する。
- 組織設定とエンタープライズコントロールを管理する。
- サービスアカウントと共有コンピューターリソースを管理する。
- 利用可能な場合は、追加利用枠を購入または設定する。

Manager は、Owner 限定の請求、支払い、アイデンティティ管理操作は行えません。

## Owner

Owner は Manager にできることをすべて行えるうえで、最も機密性の高い組織コントロールにもアクセスできます。このロールは、Factory アカウントに最終責任を負う個人またはチーム向けです。

Owner にできること:

- 請求情報と支払い方法を管理する。
- 請求ポータルにアクセスする。
- 影響の大きいサブスクリプション設定を開始または変更する。
- 利用可能な場合は、SSO、ドメイン検証、ディレクトリ同期を設定する。
- アカウント所有権が必要なアカウントのオンボーディングやプラン設定の手順を完了する。
- Owner 限定の利用状況および請求コントロールを管理する。

## 補足

実際のアクセス権は、組織のプラン、有効化されている機能、管理設定によって異なる場合があります。迷った場合は、メンバーに必要なアクセスを与えられる中で最も低いロールを割り当ててください。
